# Estúdio Norra - Nova Aplicação Web (Laravel + Filament)

Refatoração completa do website do Estúdio Norra (`estudionorra.com`), eliminando o Supabase e overengineering da versão anterior, implementando uma arquitetura simples, moderna, rápida e manutenível adequada para hospedagem compartilhada (Hostinger).

## Baseline
- Projeto original em SPA React 19 / Supabase preservado em `OLD_NORRA/norra-spa/`.
- Design de referência no Penpot: Boards `home` (desktop 1440px) e `home mobile` (mobile 360px).
- Stack: Laravel 11, Filament v3, Tailwind CSS, SQLite/MySQL, Canvas 2D Preloader.
